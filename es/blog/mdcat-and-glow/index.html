ターミナルでMarkdownを読むならmdcatとglow

READMEや設計メモを確認するたびにブラウザやエディタを開くのは少し面倒。

そんなときに便利なのが、Markdownをターミナル上で整形して表示するmdcatとglow。どちらも見出し、リスト、リンク、コードブロックなどを読みやすく描画してくれるが、使い勝手は少し違う。

mdcat

mdcatは、名前の通りMarkdown版のcat。ファイルを渡すと、その内容をターミナルへ素早く出力する。

mdcat README.md

コードブロックのシンタックスハイライトやクリック可能なリンクに対応している。iTerm2、kitty、WezTerm、Ghosttyでは画像のインライン表示も可能。数式やMermaidも扱えるため、画像や図を含むドキュメントをターミナル内で確認できる。

長い文書にはページャーを付けられる。

mdcat --paginate README.md

編集中のファイルを自動で再描画する--watchも便利。

mdcat --watch docs/design.md

テーマは組み込みのものから選べる。

mdcat --list-themes
mdcat --theme catppuccin-mocha README.md

なお、元のswsnr/mdcatは2026年6月にアーカイブされ、現在はBIRSAx2/mdcatでメンテナンスが続いている。

glow

glowは、Markdownの表示に加えてファイルを探して読むためのTUIを備えている。

glow

引数なしで起動すると、カレントディレクトリ以下、またはGitリポジトリ内のMarkdownファイルを一覧できる。ドキュメントが複数あるプロジェクトを見て回るなら、こちらが使いやすい。

もちろん、mdcatと同じようにファイルを直接表示することもできる。

glow README.md

標準入力、URL、GitHubやGitLabのリポジトリにも対応している。

git show HEAD:README.md | glow -
glow https://example.com/guide.md
glow github.com/charmbracelet/glow

表示幅、ページャー、ライト・ダークテーマも指定できる。

glow -w 100 README.md
glow -p README.md
glow -s dark README.md

毎回同じオプションを指定するなら、glow configで設定ファイルを編集できる。

インストール

macOSまたはHomebrewを使えるLinuxなら、両方まとめて導入できる。

brew install mdcat glow

RustやGoの環境がある場合は、それぞれのパッケージツールからもインストールできる。

cargo install mdcat
go install charm.land/glow/v3@latest

そのほかのOS向けパッケージやバイナリは、各プロジェクトの公式リポジトリから入手できる。

どちらを使うか

単一ファイルを素早く表示したいならmdcatが向いている。catやbatに近い感覚で使え、シェルの処理にも組み込みやすい。画像、数式、Mermaidを含む文書を確認したい場合にも強い。

一方、ディレクトリ内のMarkdownを探しながら読みたいならglowが便利。TUIでファイルを選べるので、docs/以下を巡回したり、メモをブラウズしたりする用途と相性がよい。URLをそのまま渡せるのも利点。

用途おすすめ
READMEをすぐ表示するmdcat
長い文書をページ送りで読むどちらでも可
編集中の文書をライブプレビューするmdcat
複数のMarkdownをTUIで探すglow
URLやGitHub上のREADMEを読むglow
画像、数式、Mermaidを表示するmdcat

まとめ

まず1つ選ぶなら、普段の操作で決めるとよい。

Markdown版catが欲しい   → mdcat
Markdownブラウザが欲しい → glow

競合というより役割の異なるツールなので、両方入れて使い分けるのも自然。READMEを一瞬だけ確認するときはmdcat、リポジトリ内のドキュメントを腰を据えて読むときはglow、という使い分けが分かりやすい。
